Privacy Policy

Effective September 7, 2026 · applies to the application "Health MCP"

1. Who this covers

Health MCP is a personal application operated by its developer, Jacob (Jiacheng) Zhao, for the developer's own use. It has exactly one user: the developer. It is not offered to the public, and no other person's Google account can be connected to it. This policy describes how the application handles Google user data so that its use of the Google Health API is transparent.

2. What data is accessed

With the account owner's consent through Google's OAuth 2.0 sign-in, the application reads the following categories of data from the Google Health API, using read-only permissions only:

  • Activity and fitness data — steps, distance, calories, active minutes, exercise sessions
  • Health metrics and measurements — heart rate, resting heart rate, heart rate variability, oxygen saturation, respiratory rate, temperature derivations, weight and body composition
  • Sleep data — sessions and sleep stages
  • Nutrition and hydration logs
  • Electrocardiogram records and irregular rhythm notifications, where they exist
  • Basic profile and settings information — display units, time zone, paired devices

The application never writes to, modifies, or deletes data in the Google Health account.

3. How the data is used

Data is retrieved only when the account owner asks a question. It is used solely to answer that question — for example, to summarize sleep over a period, chart heart-rate trends, or compare activity between days. It is not used for advertising, profiling, credit or insurance decisions, model training, or any purpose other than the owner's own analysis.

4. Where the data is stored

The application runs on the account owner's personal computer. OAuth access and refresh tokens are stored in a local file readable only by the owner's user account. The application operates no server, database, or cloud storage of its own, and it does not retain copies of health data beyond the duration of a request.

5. Sharing

Health data is not sold, rented, or shared with third parties for their own purposes. One transfer is inherent in how the application is used: when the owner asks the AI assistant a question, the specific data needed to answer it is included in that request and processed by the assistant's provider (Anthropic) under that provider's terms and privacy policy. No data is transferred to anyone else.

6. Google API Services User Data Policy

Health MCP's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access

Access can be revoked at any time from the Google Account's Third-party apps & services page, which invalidates the stored tokens immediately. Deleting the local token file has the same effect on the owner's computer.

8. Changes

If the way the application handles data changes, this page will be updated and the effective date above revised.
